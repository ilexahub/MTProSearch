# Кодекс поведения

Этот репозиторий — страница загрузки приложения «Выручайка» и место
для вопросов. Участники (автор и гости в Issues) ожидают уважительного
общения.

## Ожидаемое поведение

- вежливый тон, по делу;
- конструктивная критика без оскорблений;
- уважение к чужому времени и опыту.

## Недопустимо

- оскорбления, травля, дискриминация;
- публикация чужих личных данных без согласия;
- спам, реклама, флуд не по теме репозитория.

## Нарушения

Автор может закрыть Issue, удалить комментарий или ограничить доступ
к обсуждению без предупреждения при явном нарушении.

Сообщить о нарушении: новый Issue с пометкой `[conduct]` или ответ
в существующей ветке с просьбой разобраться.
