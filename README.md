# Выручайка

Выручайка помогает открывать мир, проверяет и показывает запасные пути с вашего Андроида.

**Скачать последнюю сборку :** [GitVerse](https://gitverse.ru/ilexa/MTProSearch/releases) (без VPN) · [GitHub](https://github.com/ilexahub/MTProSearch/releases/latest)

**Поддержать :** [Tribute](https://t.me/tribute/app?startapp=dPMR) · [веб](https://web.tribute.tg/d/PMR) · [звёзды Telegram](https://t.me/vyruchai_ka_bot?start=donate)

**[Как установить](docs/kak-ustanovit.md)** : подробности — пошагово, простым языком.

## Установка

Краткая памятка :

1. Скачайте APK с телефона. Android 8.0 и новее. Удобнее с GitVerse, если GitHub без VPN не открывается.
2. Разрешите установку из этого источника (браузер или файловый менеджер).
3. Откройте файл и установите.

Play Protect может показать «неизвестный разработчик»: подпись не из Google Play, это ожидаемо.

**MTProSearch (Выручайка)** — Android-приложение, которое скачивает публичные списки и перепроверяет их с сети вашего андроид.

В список по умолчанию попадают все FakeTLS из обоих файлов, кроме чёрного списка имён. Белые сайты (VK, Сбер, Госуслуги и остальные) не дают строке преимущества: имя в ссылке — прикрытие, не страна сервера.
Понимает ссылки tg://proxy и t.me/proxy.

**Проверка :**
Галки **RU / EN** выбирают, какие списки качать. По умолчанию обе, **TrueMask** выключен. Первый запуск 1.7.8 ставит это у всех; потом галки можно сузить. Внизу экрана сверху **«Проверить текущий список»** (уже живые, без повторной загрузки), под ней **«Обновить/проверить список»**.

**Сортировка :** по времени ответа. Имя сайта и порт строку не поднимают.
На Wi‑Fi проверка быстрее и параллельнее, на LTE — осторожнее. На один хост — один сокет.

В приложении само предлагает новую сборку. Если GitHub отвечает, открывается уже файл (не страница релиза). Если нет — файл с GitVerse. Права «установка неизвестных приложений» у браузера, не у Выручайки.

**Ограничения :**
HMAC не гарантирует, что доступ у вас откроется (DPI после прокси, бан IP, перегруз). req_pq ближе к «ретранслирует в DC», но без входа в аккаунт.
