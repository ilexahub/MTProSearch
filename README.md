# MTProSearch — загрузки

Публичные APK. Исходники в этом репозитории не лежат.

**Скачать последнюю сборку:** [Releases](https://github.com/ilexahub/MTProSearch-releases/releases/latest)

Файл называется `MTProSearch.x.y.z.apk`, например `MTProSearch.1.3.0.apk`.

## Установка

1. Скачайте APK с телефона.
2. Разрешите установку из этого источника (браузер или файловый менеджер).
3. Откройте файл и установите.

Если уже стоит **более ранняя debug-сборка** с того же компьютера разработки — Android может отказаться обновлять поверх. Тогда удалите старое приложение один раз и поставьте этот APK. Дальше обновления с этой страницы ставятся поверх.

Play Protect может показать «неизвестный разработчик»: подпись не из Google Play, это ожидаемо.

Сборка через 30 дней после компиляции просит скачать обновление и открывает эту страницу релизов.
