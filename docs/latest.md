# Текущая сборка: 1.5.0

На GitVerse **нет** постоянной ссылки вида GitHub `/releases/latest`. Такая страница даёт 404, в публичном API метода `releases/latest` тоже нет (список релизов через API только с токеном).

## Какую ссылку давать

| Кому | Ссылка |
| --- | --- |
| Людям на GitVerse | https://gitverse.ru/ilexa/MTProSearch/releases |
| Тем же, но с номером версии | https://gitverse.ru/ilexa/MTProSearch/releases/tag/v1.5.0 |
| Постоянная памятка (этот файл) | https://gitverse.ru/ilexa/MTProSearch/content/main/docs/latest.md |
| Тем, у кого открывается GitHub | https://github.com/ilexahub/MTProSearch/releases/latest |

Список релизов GitVerse открывается без входа. Сверху всегда новая сборка, у неё бейдж **«Последний»**. Скачивайте файл `MTProSearch.1.5.0.apk`.

Прямую ссылку на файл с `api/attachments/…` не копируйте: UUID меняется при каждой загрузке APK.
